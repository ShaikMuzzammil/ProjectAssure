# Workflow 05 · Create a project

**One line:** Register a new project through a guided 6-step wizard that explains every field — and comes alive the moment it is created.

**Who uses it:** project managers and admins registering real work.

## Click path
1. **Projects** (sidebar) → **New project** (top right).
2. Step 1 **Basics** — name, department, sector, state, district, scheme. Each field has a hint.
3. Step 2 **Stage & people** — choose **Still in planning** (baseline prediction from day one) or **Execution underway** (full 18-signal scoring) + project manager + contractor.
4. Steps 3–4 **Schedule & budget** — duration slider, sanctioned budget.
5. Step 5 **Documents** — optional here (see workflow 06); you can also upload after creation.
6. Step 6 **Review** → **Create project**.

## What happens the moment it is created (nothing is empty)
- The project detail page opens **alive**: budget phasing (S-curve), resources, 4 starter milestones, onboarding alerts, KPI seeds.
- A **prediction runs automatically** — baseline for planning-stage projects, full scoring for execution-stage.
- A live risk register is assembled: document risks + engine signals + project context (monsoon, land acquisition, contractor status…).
- The project appears on the **map** (geocoded to its district), in **search**, and in the live feed.

## Verify it worked
- Open the new project → Overview shows the risk register card with counts ("N live risks · X from documents · Y from context").
- Alerts Centre shows the onboarding alerts; the dashboard counts update.

## Under the hood (honesty)
New projects start Green (~95) by design — the engine's early-phase neutrality guards mean "no evidence yet" is never punished as "at risk" (this was a real fixed bug).
