# Workflow 03 · Explore the dashboard

**One line:** Open the Dashboard and see, in one screen, what needs attention today, why, and what to do about it.

**Who uses it:** everyone — this is the home screen after sign-in.

## Click path
1. Sign in (workflow 02) → you land on **Dashboard**.
2. Read the top band: four big numbers (portfolio value, healthy / at-risk / critical split, live risk count).
3. Read **"Requires attention today"** — one plain-language card per project that needs you, with a *What to do* button.
4. Scroll to the live feed (portfolio events, ticking) and the risk exceptions strip.

## What you see
- **Big numbers** — always derived live from the projects your role can see.
- **Attention cards** — "Bharatmala P-4 is 44 days behind because permits are pending" style sentences, never just a red dot.
- **Ask Intelligence** chip — one click sends "what needs my attention?" to the assistant.
- Export buttons (CSV / Excel / PDF) for the whole view — audit-logged.

## Verify it worked
- Click any attention card's action → it opens the right project at the right tab.
- Press the export button → a real file downloads and a toast confirms an audit entry.

## Under the hood (honesty)
Every number is recomputed by the same engine that scores projects (no separate dashboard math), so the dashboard and project detail can never disagree.
