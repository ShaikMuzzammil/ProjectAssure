# Workflow 04 · Compare projects

**One line:** Put up to four projects side by side on nine metrics and get an honest verdict on which needs review first.

**Who uses it:** portfolio overseers, analysts, reviewers deciding priorities.

## Click path
1. Open **Projects** (sidebar).
2. Open any project → the compare entry point (⌘K "compare", or the in-screen link) → **Compare Projects**.
3. Pick up to 4 projects from the selectors.
4. Read the metric table and the **verdict** line at the bottom.

## Metrics compared
Sanctioned budget · revised budget · spent · physical progress vs plan · health score · open alerts · milestone adherence · risk register count · delay probability.

## Verify it worked
- The verdict names one project and says why in one sentence (e.g., "needs priority review: lowest health with rising burn").
- Export the comparison as PDF — a side-by-side document with the verdict.

## Under the hood (honesty)
Comparison reads the same per-project engine values (no re-computation), so numbers match every other screen.
